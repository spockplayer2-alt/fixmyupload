# Privacy policy

Effective November 2, 2026.

FixMyUpload processes chosen files and pasted upload errors inside your browser. It does not transmit those contents, create accounts, collect analytics, use advertising, or call an external conversion or AI service.

Files, parsed text and results are kept in the current page's memory. There is no file persistence or service-worker cache. If you explicitly choose Save preset, the app stores requirements and image settings in localStorage on this device. No filenames, file contents or pasted errors are stored. Delete a preset using its delete control. Reloading or closing the page clears the app's references. Temporary object URLs are revoked when a file/result changes or its component closes. Downloaded files remain wherever your browser saves them; deleting them is your choice.

The static host receives normal page/asset requests, which can include your IP address, request time and browser headers. The host's own privacy policy applies to those requests. Visiting the source link opens GitHub. The app loads its JavaScript, icons and styling from its host and serves its Geist font locally and has no tracking scripts.

Browser extensions, your operating system, and a website you later upload the corrected file to have their own behavior and policies. FixMyUpload cannot control them. View the [source repository](https://github.com/spockplayer2-alt/fixmyupload) or open an issue for questions without including sensitive documents.
