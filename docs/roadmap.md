# Roadmap

These are possible next steps, not available features or dated promises:

- Add Firefox and WebKit browser CI and more mobile device testing.
- Expand conservative English parsing from real, anonymized error messages.
- Evaluate a dedicated image worker and additional reliable codecs.
- Improve PDF form and accessibility preservation with explicit fixture coverage.
- Investigate advanced PDF compression only with a dependable browser implementation and honest output validation.

Local processing and clear failure states remain requirements for future work.
