# Code of conduct

Be respectful, patient and constructive. Discuss ideas and code without attacking people. Harassment, discrimination, threats, doxxing and unwelcome sexual attention are not acceptable.

This applies to issues, pull requests and other project spaces. Don't post private information or other people's files. Assume good intent, accept feedback, and respect requests to stop a discussion.

Report concerns privately using the security contact route in [SECURITY.md](SECURITY.md); if that route is unavailable, ask the maintainer for private contact without identifying affected people publicly. The maintainer may remove content, close discussions, or restrict participation to protect contributors. Enforcement should be proportionate and respect the privacy of everyone involved.
